# Fileora starter

## Included
- Image compressor
- Image resizer
- Image converter
- PDF merger
- PDF page extractor
- PDF-to-PNG conversion
- Word/character/line counter
- Upper/lowercase converter
- Extra-space remover
- Copy/clear text
- About, Privacy Policy, Terms and Contact pages
- Responsive design
- Empty ad-slot containers (no fake ads)

## Important
1. Replace `support@YOUR-DOMAIN.com` with a real email address you control.
2. Replace the site name/domain metadata with your real domain.
3. Test every tool on your deployed HTTPS domain and on mobile.
4. The PDF tools use PDF-LIB and PDF.js from cdnjs. If you want a fully self-hosted build, download and host those libraries yourself.
5. Do not add fake advertisements or clickable ad placeholders. Add the official AdSense code only after your AdSense account/site is approved and use Google's current placement rules.
6. Approval and earnings are never guaranteed by code alone. Build useful original pages/content and a trustworthy user experience first.

## Fileora launch checklist
- Replace `YOUR-DOMAIN.com` in `robots.txt` and `sitemap.xml`.
- Replace the support email placeholder in `contact.html`.
- Update the copyright year if desired.
- Deploy over HTTPS.
- Test every tool on desktop and mobile.
- Add real AdSense code only after the site is approved.
